# Android 系统日历同步

在 Android 客户端的「课表 → 我的日程」点击「导入日程」，授予日历读写权限，再选择提醒时间和是否自动同步。课程会写入单独的「RemoteCI 我的日程」本地日历，由系统日历应用发送提醒。默认课前 10 分钟，可改为开始时、提前 5、15 或 30 分钟。

启用自动同步后，个人日程轮询及「我的日程」页面会检查更新；应用未打开时使用系统后台任务，约每 15 分钟同步一次。后台实际执行时间受联网状态、省电策略和系统调度影响。已导入事件的提醒由系统日历管理，不需要 RemoteCI 持续运行。请保持该日历可见，并允许系统日历应用发送通知。

再次导入会更新已有课程。课程以日期、班级、节次识别；自定义课程以课程 ID 识别，修改日期也会更新原事件。课程名称、时间、班级地点变化会更新日历，取消的未结束课程会删除，已结束事件保留。同步范围仅包含 RemoteCI 导入的事件。课程时间优先使用服务端给出的绝对时间或班级时区；旧服务端缺少时区时回退到手机时区。

这是从 RemoteCI 到系统日历的单向同步。修改课程请在 RemoteCI 进行；直接在系统日历修改导入事件后，后续同步会恢复为 RemoteCI 中的内容。独立添加到日历的事件不会被同步管理。每次成功导入都会按照当前设置更新课前提醒。

关闭自动同步后仍可手动导入，已有事件及其提醒保留。退出登录会停止自动同步；切换账号或服务器后需为新身份重新导入，旧日历不会被改写。

权限被拒绝、设备没有日历服务、服务器不可达或日程格式无效时，界面显示失败原因，保留已有日历事件。日历写入采用批量事务，避免事件写入成功但提醒缺失。

验证命令：

```powershell
cd android
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

设备验证时依次检查：首次授权和导入、再次导入无重复、修改课程名称及时间、取消未来课程、修改提醒提前量、关闭自动同步、退出登录、重启后后台同步、拒绝和撤销日历权限。系统提醒需在安装有日历应用的设备上验证。
