# 手机 WebUI、PWA 与系统日历

手机打开 RemoteCI 会自动进入手机界面。小屏触摸设备也会在浏览器中自动切换；电脑缩小窗口不会触发切换。页面底部的“更多操作请进入电脑版”中，蓝色“电脑版”进入对应的完整页面，并记住选择一年。电脑版在手机上按设备宽度正常显示（不缩放成桌面宽度），顶栏可返回手机版。

手机界面沿用安卓版的今天、课表、换课、控制和管理入口，默认使用绿色 Material 3 配色，可在“账号与设置 → 外观”改为淡紫、经典紫、蓝、橙或粉色。网页端图标统一使用与安卓端同源的 Material Symbols Rounded，粗细一致。换课及管理入口按账号权限显示；没有“概览”权限的账号仍可按原有班级权限使用手机功能。桌面端权限不会因此放宽。档案编辑、批量控制、分组和调休等复杂操作通过电脑版完成。

## 安装与通知

1. 使用有效证书的 HTTPS 地址访问。HTTP 局域网页面仍能查看和操作，但不能开启 PWA 推送或浏览器麦克风（localhost 开发环境除外）。
2. iPhone/iPad 需 iOS/iPadOS 16.4 或以上：用 Safari 分享菜单选择“添加到主屏幕”，然后从桌面图标打开。Android 等支持安装提示的浏览器可直接点击安装。
3. 登录后打开“账号与设置 → 通知设置”，点击“开启浏览器通知”，允许系统权限，再发送测试通知。
4. 按需选择上课、下课、放学、课表变化、自定义消息、自动化和第三方插件通知。课堂事件跟随本浏览器最后选择的班级；个人课程与换课通知按账号接收。

推送由服务端发送，手机无需保持网页或 WebSocket 后台运行。服务端须能通过 HTTPS 访问 `*.push.apple.com`；其他浏览器可能使用 FCM、WNS 或 Mozilla Push，需有相应出站网络。无需苹果开发者账号或原生 APNs 证书。

VAPID 密钥保存在数据库，完整数据库备份需要同时保留它们。联系地址可用 `Server__WebPushSubject` 配置，默认项目公开主页。更换密钥后需重新开启通知。

消息先进入持久化投递队列，支持重试和重启恢复。课堂事件五分钟后过期；课前提醒在开课时过期，上课提醒在课程结束时过期，换课消息最长一天。404/410 会清理失效订阅。退出登录解除本浏览器绑定；改密、禁用等撤销全部会话的操作也会清理该账号的浏览器订阅。

可通过 `WebPushWorker` 日志查看积压、成功、重试和最终失败。投递被推送服务接受不等于用户已看到，系统权限、专注模式和网络仍影响展示。应用不模拟安卓的后台常驻通知、持续锁屏倒计时和系统动态配色。

## 系统日历

“账号与设置 → 系统日历”或课表页提供两种独立订阅：

- **我的日程**：自己的任教课程和自定义课程。
- **班级课表**：固定绑定某个有权访问的班级，之后切换查看的班级不影响已订阅的日历。

选择提醒时间，生成链接后点击“添加到系统日历”；也可复制 HTTPS 地址，在苹果日历的“添加订阅日历”中粘贴。私密链接仅本次显示，数据库只保存令牌摘要。重复生成同一内容会使原链接失效，需要设备重新订阅。提醒设置可单独修改而不更换链接；自定义课程使用课程自身的提醒设置。

班级和任教课程使用服务器已有的七日课表，自定义课程按保存日期输出。没有教室端课表时沿用档案推算并标记来源，不另外推算未来周。修改课程会更新同一事件；取消的未来课程发送取消状态，最近结束的事件及取消记录保留三十天。

日历由系统定期刷新，不能作为临时换课的即时通知通道。开启系统日历的事件提醒，并确认没有启用“移除提醒”。日历和推送都启用课前提醒时可能重复提示。

撤销链接或失去班级访问权后，服务器停止提供内容；已下载的事件不会被远程擦除，请在系统日历中取消订阅。配置包恢复会清理通知订阅、日历链接和待发任务，恢复后重新订阅；完整数据库恢复则保留这些状态。代理/CDN 应禁用这些接口的缓存，并对 `/calendar/` 的私密令牌在访问日志中脱敏。

## 离线与验收

在本设备打开过课表后，断网可查看最近保存的一份只读课表，页面标明保存时间。退出或切换账号会清理缓存；离线不能执行控制、管理或换课操作。

开发回归覆盖手机识别、手动切换、页面权限、防伪验证、课表写入、日历身份与更新取消、链接撤销、通知队列重试及失效订阅。发布前仍需 iPhone 真机验证主屏幕安装、锁屏和关闭页面后的通知、通知点击跳转、日历刷新与提醒；桌面浏览器模拟不能代替这些检查。
