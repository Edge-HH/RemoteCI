# RemoteCI 3.3.2.1

本次更新是 3.3.2.0 的跟进发布：班级策略新增“禁止插件设置”，并修复飞牛 fnOS 的应用版本格式。

## 班级策略

- 新增“禁止插件设置”（`disablePluginsSettings`）：隐藏 ClassIsland 自带的“插件”页，不能本地安装、卸载、启用或禁用插件；各插件自己的设置页不受影响。在班级管理页与批量控制页随班级策略一起保存和下发。

## 修复

- 修复飞牛 fnOS 应用中心拒绝四段版本的问题：manifest 版本改为 `x.y.z-m` 三段式（例如 `3.3.2-1`），镜像标签与 FPK 文件名仍为四段。

## 升级说明

- 软件版本为 **3.3.2.1**，通信协议仍为 **V3**。
- “禁止插件设置”需要同时更新服务端和 ClassIsland 插件；旧插件忽略该策略项。
- 升级前请备份 SQLite 数据卷。
