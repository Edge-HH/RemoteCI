# RemoteCI 3.3.0.2

本次更新完善老师换课、插件扩展管理和 Android 日常使用体验，并修复多端权限与登录衔接问题。以下内容相对于 3.3.0.1。

## 课表与管理

- 新增老师临时换课申请：支持发起、审批和按权限强制换课，WebUI 与手机提供申请入口；永久换课仍由班主任在课表页完成。
- 新增个人通知中心和浏览器推送，集中接收换课申请及处理结果；关闭网页后接收推送需要 HTTPS 和可达的浏览器推送服务。
- 插件扩展支持参数表单、插件分组与设置页面，可批量执行并统一下发设置；离线设备的待应用设置在重新上线后处理。
- 系统管理员可统一配置班主任修改本班名称、头像、拉取课表和修改扩展设置的权限。

## Android 手机

- 新增当前时间状态、今日课表和换课桌面小组件，适配深色模式及 HyperOS 常用尺寸，按账号、服务器和班级隔离缓存。
- 小米设备在审核通过前通过“搜索 → 安卓小部件”添加 RemoteCI；独立小部件中心展示需通过小米审核后开启。
- 完善“上课状态”持续通知，显示阶段倒计时、当前课与下一节课；老师使用跨班级个人日程，支持系统允许的 HyperOS 焦点通知、超级岛、AOD 与 Android 16 Live Update 展示。
- WebUI 可生成一次性手机登录二维码，并配置二维码中的服务器地址；登录页和连接设置页共用竖屏扫码页面，支持手电筒和相册二维码识别。
- 手机打开 WebUI 时使用一次性网页登录票据，自动登录当前账号；修复打开网页后被送回登录页的问题。
- 优化管理入口、账号角色选择、插件配对码复制、主题及底栏转场。

## 通知、权限与稳定性

- 自定义通知支持持续时间、重复次数和正文滚动开关；WebUI 与手机默认静态显示，旧客户端省略滚动开关时保留原有行为。
- 统一通知参数上限：标题 60 字、正文 500 字、持续时间 3600 秒、重复 10 次；空正文只显示标题。
- 修复云端与局域网有效权限不一致的问题，按目标班级复核控制权限。
- 网页登录票据持久化并原子消费，避免重启、多实例或并发消费导致登录异常。
- 完善 Android、Wear OS 与服务端测试，更新依赖和 CI 构建流程。

## 升级说明

- 软件版本为 **3.3.0.2**，通信协议仍为 **V3**；建议同步更新服务端、ClassIsland 插件、Android 手机及 Wear OS 客户端以使用完整新功能。
- 升级前备份 SQLite 数据卷。本次包含数据库迁移，换课申请、个人通知和推送订阅等运行数据随数据库备份保存。
- 发布产物包括 Windows/Linux 服务端、ClassIsland 插件包、手机与手表 APK、fnOS 在线及双架构离线包，并发布多架构容器镜像。
