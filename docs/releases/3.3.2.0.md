# RemoteCI 3.3.2.0

本次更新新增班级策略和 ClassIsland 设置远程读写，课表改为多彩课程表，应用守护可以独立在线和远程管理，权限改为“角色默认 + 个人新增/收回”，界面整体换新。以下内容相对于 3.3.1.8，包含 3.3.1.9 预发布版的改动。

## 班级策略与 ClassIsland 设置（新）

- 系统管理员可以按班设置策略：禁止编辑课表、时间表、科目、档案和设置，禁用调试菜单，限制退出集控、修改连接信息和打开插件设置页。策略在设备上线时和修改后下发，离线时也会生效。
- 新增“ClassIsland 设置”弹窗，可以远程读取和修改教室端约 120 项 ClassIsland 设置，单班和批量控制都能用。也可以通过 REST 接口 `/api/classisland-settings/catalog` 和 `/api/classes/{id}/classisland-settings` 调用。

## 多彩课程表

- WebUI 和 Android 的课表、我的日程都改为多彩周表格：学科颜色色块、连堂合并、分割线，并标出放假、调休和换课，可以翻周。Android 还支持双指缩放。
- 学科颜色跟着账号同步。显示老师、班级、地点、周末，以及是否合并连堂，可以自行设置。
- 新增“科目地点”，会显示在课表、“今天”页和日历中。另外新增按周取课表的接口 `/api/schedule/week` 和 `/api/me/schedule/week`。

## 换课与日程

- 换课和换课申请可以选 30 天内的任意一天，各端都改用日期选择器；课表页新增“申请换课”入口。
- 自定义课程改为在一张表里统一管理，编辑在弹窗中完成。

## 应用守护

- 课表插件离线时，守护仍保持在线。可以远程打开 ClassIsland，也可以关闭、卸载守护。
- 应用守护页可以一键“更新守护”。守护丢失或版本过旧时，插件会自动补装或替换。
- 新增 UAC 增强模式（Windows 服务）、额外备份路径，以及“开机自动启动”开关。

## 控制与插件

- 新增“主界面文件”上传和下载，可以覆盖当前方案，也可以新建一份并切换过去，失败时会自动恢复。
- “安装插件”可以直接浏览插件市场。新增“从 CIPX 安装”，服务端会预先下载并校验。
- 控制页可以自定义常用磁贴和控制项顺序。

## 账号与系统

- 权限改为“角色默认 + 个人新增/收回”，各功能拆成独立权限。升级时会自动补齐，行为不变。
- 登录可以输入 ID 或用户名，两者全局唯一。密码允许英文符号。登录会话的有效期延长到 30 天。
- 系统更新会记住所选渠道，并支持自动检查和自动下载（不会自动安装）。
- 设备状态中，每个班只显示最后连接的设备。

## 界面

- WebUI、移动版和 Android 换成清新低饱和的配色和同心圆角，深色模式更清晰。
- 侧边栏合并为“班级管理 / 管理 / 记录与统计”，概览页精简；WebUI 换页时不再闪烁。

## 修复

- 修复守护消息时间戳格式错误，导致能力、命令和事件被丢弃的问题。
- 修复旧版守护配置导致部署失败的问题，以及 ClassIsland 2.1.1 下恢复提示崩溃的问题。
- 修复新建账号失败后班级列表被清空、检查更新后设置显示为默认值、Android 表头日期被裁切等问题。

## 升级说明

- 软件版本为 **3.3.2.0**，通信协议仍为 **V3**。插件 SDK 升级到 2.1.0.1，**最低支持 ClassIsland 2.1.0**。
- 新功能需要同时更新服务端和插件。旧守护会在插件上线后自动更新。
- 升级前请备份 SQLite 数据卷，本次包含多项数据库迁移。
- 发布产物新增 linux-arm64 服务端包。AstrBot 插件和 Skill 已同步更新。
