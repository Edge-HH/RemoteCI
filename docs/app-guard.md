# 应用守护

管理员可以在 RemoteCI 后台统一开启“应用守护”，让教室电脑上的 ClassIsland 始终保持运行：

- **退出自启**：ClassIsland 被正常退出后自动重新启动。可设置延时，例如“退出 40 分钟后自启”；0 表示立即（实际至少等 10 秒，让 ClassIsland 自己的重启先完成）。
- **意外退出时重启**：ClassIsland 崩溃或在任务管理器中被结束进程时，5 秒后重新启动。10 分钟内意外退出超过 3 次时，暂停自动重启 10 分钟，并上报“频繁崩溃”事件。
- **增强守护**：首次启用时在教室电脑上请求 UAC 管理员授权，安装固定名称的 Windows 自动启动服务 `RemoteCI.Guard` 和登录任务 `RemoteCI\Guard Agent`。服务只维护普通权限用户代理，不以管理员身份启动 ClassIsland；拒绝授权时保留普通守护。
- **独立云端通道**：守护使用同一设备凭据独立连接服务器。ClassIsland 与插件退出后设备仍显示“守护在线 · 课表离线”，系统管理员可从控制页远程打开 ClassIsland。
- **多路径备份**：除默认备份外，最多设置 3 个额外绝对路径；每个目标使用独立的 `RemoteCI.Guard.Backup` 副本和清单，恢复时逐个尝试。还可在 `%LOCALAPPDATA%\RemoteCI\ProtectedBackups` 下启用 ACL 受限的安全备份目录，子目录名可自定义，留空则随机生成并复用。
- **自定义守护进程名**：可设置字母、数字、点、下划线和连字符组成的代理文件名。改名时插件会迁移登录自启项和增强任务；代理始终从 `%LOCALAPPDATA%\RemoteCI\Guard` 运行，增强服务从 `%ProgramData%\RemoteCI\Guard` 运行，均不占用或锁定 ClassIsland 安装目录。
- **禁止删除**：定时把 ClassIsland 备份到默认位置和额外目标。检测到程序被删除后，从备份恢复、重新启动，然后用 ClassIsland 原生对话框提示：

  > 当前ClassIsland由{组织名}统一管理，请勿自行删除，当前实例已由RemoteCI自动恢复。

  其中的组织名在“系统配置 › 组织信息”中设置；不填时显示 RemoteCI。

## 在哪里设置

| 位置 | 内容 |
| --- | --- |
| WebUI › 管理 › 应用守护 | 全局策略、单台设备的单独设置、更新/关闭/卸载守护、最近守护事件 |
| WebUI › 系统配置 › 组织信息 | 恢复提示中的组织名 |
| REST | `GET/PUT /api/settings/app-guard`、`GET/PUT/DELETE /api/devices/{credentialId}/app-guard`、`GET /api/app-guard/events`（需要“应用守护策略”系统权限；直接关闭、卸载或更新设备守护另需“设备应用守护”权限，见[协议](protocol.md#应用守护)） |

全局策略对所有教室电脑生效。某台设备单独设置后，它使用自己的完整策略，直到点“恢复沿用全局”。策略保存后立即下发给在线设备；离线设备在下次连接时收到。插件会缓存最近一次收到的策略，断网启动时照样生效。

设备列表分别显示课表插件与独立守护的在线状态。课表离线而守护在线时，仍可通过设备行的“关闭守护”或“卸载守护”操作该设备。守护声明 `host.app-guard-manage` 能力后这些操作才可用；旧守护会提示“守护版本过旧”。课表插件在线时，插件一分钟内会用插件包里的新版守护自动替换它；也可以点设备行的“更新守护”立即强制覆盖升级，失败原因（如文件被占用）会直接显示在页面上。课表插件本身过旧时提示先升级插件；插件离线时提示上线后自动更新。设备行会显示在线守护的版本；守护在线、能力完整且版本与课表插件一致即视为最新，不显示“更新守护”，其余情况（守护离线、能力不全或版本不同）在策略启用、课表插件在线时显示。替换用户目录下的守护代理不需要 UAC。课表插件在线但未声明 `host.app-guard` 时显示“插件版本过旧”。

## 工作原理

ClassIsland 退出或被删除时，插件也随之停止，所以守护工作由一个独立的小程序 `RemoteCI.Guard.exe` 完成。它随插件包分发，基于 Windows 10/11 自带的 .NET Framework 4.8，因此即使 ClassIsland 连同它自带的运行时一起被删除，它也能运行。

1. 插件收到启用的策略后，把 `RemoteCI.Guard.exe` 复制到 `%LOCALAPPDATA%\RemoteCI\Guard`，写入守护配置，在当前用户的注册表 `HKCU\...\Run` 中登记登录自启，并启动它。整个过程不需要管理员权限。
2. 守护进程每 5 秒检查一次：ClassIsland 是否在运行（安装目录下的任何进程都算，包括启动器和自带更新器）、启动器是否还在。
3. 插件启动时写入“运行中”标记，ClassIsland 正常退出时写入“正常退出”标记。守护进程据此判断：
   - 有正常退出标记：按“退出自启”的延时启动。
   - 没有正常退出标记：视为意外退出，按“意外退出时重启”处理。
4. 通过 RemoteCI 远程升级 ClassIsland 时，插件先写入“升级中”标记。之后 15 分钟内守护进程不做干预。
5. 守护进程登录 Windows 后启动时，如果 1 分钟内 ClassIsland 没有自己启动，并且开启了任一自启项，就由它启动 ClassIsland。
6. 注销或关机时，守护进程不再启动任何程序。插件每分钟检查一次守护：进程被结束时重新拉起；守护程序或配置文件被删除时重新部署；守护程序与插件包里随附的版本不一致时，结束旧进程并替换为新版本。维护过程不弹 UAC，增强服务的安装或路径变更仍在下次收到策略时处理。守护刚通过云端通道执行了远程关闭或卸载时，插件不再拉起它。
7. 插件把云端地址和由当前用户 DPAPI 加密的设备令牌写入 `connection.json`。守护以 `client=guard` 建立独立 WebSocket，声明 `host.app-guard`、`host.app-guard-launch` 与 `host.app-guard-manage`，只接收守护策略、远程打开以及关闭/卸载命令，不接收班级账号、课表或普通控制命令。
8. 同一凭据的插件与守护可同时在线，不同设备仍互斥。插件与守护都离线才记为设备离线；守护断线不会使进行中的课表拉取任务失败。
9. 增强模式的服务文件位于 `%ProgramData%\RemoteCI\Guard`。Windows 服务在后台运行，并通过任务计划程序在交互式用户登录后启动普通权限代理。远程打开要求 Windows 用户已登录。

### 备份与恢复

默认备份目录是 `%LOCALAPPDATA%\RemoteCI\Guard\backup`；额外目标写入各自目录下的 `RemoteCI.Guard.Backup`。源目录与备份目标不能互相嵌套。备份范围包括：

- ClassIsland 安装目录，含文件夹版的 `data` 目录、插件与配置；
- 位于安装目录之外的数据目录，例如 `%LOCALAPPDATA%\ClassIsland` 中的集控与全局设置。

日志、缓存和临时文件不备份。

**何时备份**：仅在 ClassIsland 运行时，按设置的间隔（默认 24 小时）增量备份，只复制有变化的文件；ClassIsland 版本变化后立即备份一次。以下情况跳过本次备份，并上报“备份失败”：

- 需要备份的文件超过 2 GB；
- 安装目录比上次备份少了 30% 以上的文件（疑似正在被删除）。

**如何判断被删除**：启动器（文件夹版为安装目录下的 `ClassIsland.exe`）或安装目录缺失，10 秒后复查仍缺失。

**如何恢复**：只补回缺失的文件，不覆盖仍存在的文件，也不删除多出来的文件。恢复后先留下提示，再启动 ClassIsland；新实例中的插件读到提示后弹出原生对话框。恢复失败时上报“恢复失败”，5 分钟后再试。

### 事件与通知

守护事件包括：已自动恢复、恢复失败、意外退出后重启、退出后自启、频繁崩溃暂停重启、备份完成（首次或版本变化后）、备份失败、增强安装失败与远程启动。

- 事件先记录在守护目录，由插件或守护云端通道上报，显示在“应用守护”页并保留 90 天。
- “已自动恢复”和“恢复失败”还会通知全部系统管理员，个人通知种类为 `app_guard`。

### 关闭与卸载

守护独立在线时，即使 ClassIsland 与插件离线，也可在“应用守护”页对单台设备执行：

- **关闭守护**：停用守护策略，结束守护进程并删除登录自启项，但保留守护程序和增强服务，之后重新启用策略即可恢复。该操作不需要 UAC。
- **卸载守护**：先请求 UAC 卸载增强服务与登录任务，再停用策略、结束守护进程并删除登录自启项；守护进程退出后延迟删除默认目录及所有额外备份目标。取消 UAC 或卸载失败时不清理本地文件。

两种操作成功后都会保存该设备的停用覆盖，避免下次连接时被原全局策略重新拉起。通过全局策略或单台设备表单关闭 `enabled` 仍由插件按完整策略执行原有清理流程；只有守护在线且声明 `host.app-guard-manage` 时，设备行才显示上述独立操作。

## 限制

- 守护服务名、任务名和安装位置固定，代理文件名与安全备份子目录名可由管理员配置；配置与日志可审计。不提供隐藏进程、仿冒系统进程或规避安全软件功能。
- 只有守护在线而课表离线时，控制页仅显示“远程打开 ClassIsland”，不显示课堂、音量、截图、扩展或班级设置控件。
- 用户代理由普通 Windows 服务与登录任务维护，用来减少误退出，**不是**不可绕过的防篡改机制。本机管理员仍可停止服务、修改任务或删除备份。
- 额外备份路径所在磁盘不可用时会记录失败；至少一个目标成功即保留可恢复副本。
- MSIX（应用商店）安装的 ClassIsland 位于系统保护目录，不支持“禁止删除”。其余两项照常生效，并会上报一次说明。
- 只守护当前登录用户的 ClassIsland。多个 Windows 账号需要各自登录过一次 ClassIsland，插件才会为该账号部署守护进程。
- 守护目录在 `%LOCALAPPDATA%` 中。如果整个用户配置文件被删除，备份也会一起丢失。

## 守护目录文件

| 文件 | 写入方 | 用途 |
| --- | --- | --- |
| `<配置的进程名>.exe`（默认 `RemoteCI.Guard.exe`） | 插件 | 守护进程 |
| `policy.json` | 插件 | 生效策略、启动路径、安装目录、备份范围、ClassIsland 版本 |
| `state.json` | 插件 | ClassIsland 的进程号与 `running` / `exiting` / `updating` 标记 |
| `guard-status.json` | 守护进程 | 心跳、独立云端状态、最近备份时间与大小、最近错误 |
| `connection.json` | 插件 | 云端地址与 DPAPI 加密的设备令牌，仅当前用户可读 |
| `pending-notice.json` | 守护进程 | 恢复后待显示的提示，插件显示后删除 |
| `events.jsonl` | 守护进程 | 待上报的守护事件 |
| `guard.log` | 守护进程 | 日志，超过 1 MB 时轮换为 `guard.log.1` |
| `backup\` | 守护进程 | 备份副本与 `manifest.json` |
